SIGNAL

A co-op mystery game where your squad races to solve a case together.

PlayHost a drop

How it works

  1. Host a drop. One player opens SIGNAL and starts a new case.
  2. Share the code. Friends join with the 4-letter code, like KQZT.
  3. Solve it together. Everyone holds different clues. Pool what you know and name the culprit before time runs out.
